# RickyMortyApi

Repositorio de prácticas del bootcamp de [Hack a Boss](https://hackaboss.com/). Su parte principal es una web que muestra los personajes de **Rick y Morty** con la [Rick and Morty API](https://rickandmortyapi.com/), y además guarda el material y los ejercicios del módulo de Node.js.

🔗 **Demo:** [inakipfrickymorty.netlify.app/pruebas/rickymorty](https://inakipfrickymorty.netlify.app/pruebas/rickymorty/)

## Web de Rick y Morty (`pruebas/rickymorty/`)

Carga los personajes de la API página a página (20 por página) y pinta una tarjeta por personaje con su imagen, nombre, especie, origen y episodios.

- JavaScript sin frameworks, con `fetch` y `async/await` (`script.js`)
- Estilos en Sass (`CSS/estilos.scss`) y `normalize.css`

Para verla en local, abre `pruebas/rickymorty/index.html` en el navegador.

## Resto del contenido

| Carpeta | Qué es |
| --- | --- |
| `mod3-node-main/` | Material de clase del módulo de Node.js, por días (`dia01` a `dia05`): módulos, CommonJS, eventos, argumentos, npm... También está comprimido en `mod3-node-main.zip` |
| `node/Ejercicio1` a `Ejercicio3` | Enunciados de los ejercicios de Node |
| `node/diario-de-viajes` | API del proyecto «Diario de viajes» (Express + MySQL). Tiene su propio repo: [diario-de-viajes](https://github.com/cosmona/diario-de-viajes) |
